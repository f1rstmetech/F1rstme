# F1RSTME Luxury Fashion Website

A mobile-first luxury fashion storefront inspired by premium editorial layouts, with an original F1RSTME identity.

## Included
- Responsive homepage
- Collection/product cards
- Men / Women / Accessories sections
- Full-screen mobile/desktop menu
- Working demo shopping bag
- Newsletter form
- Our Story section
- Instagram links
- GitHub Pages / Netlify friendly static files

## Replace before launch
1. Replace the gradient product blocks with your real product images.
2. Replace the text F1RSTME mark with your official logo if desired.
3. Update Instagram URL.
4. Connect checkout/payment gateway and order backend.
5. Add real product data and inventory.

Open `index.html` directly for a preview.
